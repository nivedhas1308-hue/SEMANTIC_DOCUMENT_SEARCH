# Week 12 - Semantic Document Search

## Objective
To develop a semantic document search system using LangChain and ChromaDB.

## Technologies Used
- Python
- LangChain
- ChromaDB
- Sentence Transformers
- Pandas
- Jupyter Notebook

## Implementation
1. Created 10 text documents.
2. Added documents to ChromaDB.
3. Created 15 user queries.
4. Performed semantic searches.
5. Retrieved Top-5 documents for each query.
6. Calculated similarity distances.
7. Compared semantic search with keyword search.

## Observations
- Semantic search understands the meaning of queries.
- Keyword search matches words directly.
- Semantic search can identify relevant documents with different wording.
- Keyword search may miss documents that use different words.
- Vector embeddings improve document retrieval.

## Conclusion
Semantic document search provides more meaningful results than traditional keyword-based search. It will be useful for developing a RAG-based question-answering system.
